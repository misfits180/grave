# Pre-built Grave Alive releases

These files are built against **7 Days to Die V 2.6 (b14)** game assemblies.

## Quick install

1. Download `grave-v0.4.1-7dtd-2.6.zip` (latest) or only replace
   `Config/entityclasses.xml` with `entityclasses-fixed.xml`.
2. Extract it.
3. Copy the `grave` folder into your mod folder:
   - `C:\Users\<you>\AppData\Roaming\7DaysToDie\Mods\grave`
4. Start the game with **Easy Anti-Cheat off**.

If you already have a `grave` folder with `ModInfo.xml` and `Config`, you can
instead copy only `GraveAlive.dll` from this folder or zip into that mod folder.
